PRIVATE PROFILE

Set up ApplyPilot

Start with your resume. ApplyPilot builds a reviewable profile and keeps it in this browser. It does not upload your profile to a developer cloud service.

Automatic assistance

When enabled, opening ApplyPilot automatically scans the current page and fills approved profile values. High-risk questions such as sponsorship, work authorization, salary, and demographic questions stay manual.

1. Add your resume

Upload a resume to extract basic application facts. Extraction creates a proposal; it does not overwrite your approved profile automatically.

TXT, Markdown, and JSON work inside the extension. PDF and DOCX use the optional local parser; it must be running on your computer.

No resume proposal yet. Upload a resume and choose Extract details.

Advanced: view extracted profile JSON

2. AI agent (Claude)

The local service can use Claude to draft answers to new questions, score your fit for a job, and write a tailored resume, cover letter, and outreach message. Your Anthropic API key stays in the local service on this computer and is never stored in the browser. Sensitive questions (work authorization, sponsorship, salary, demographics, legal consents) are never drafted.

Claude tailors from this text and never adds experience that is not here. It fills in automatically when you extract a resume above; you can edit it any time.

Many company career pages embed Greenhouse, Lever, Workday, Ashby, and similar forms inside a frame. Allowing embedded forms lets ApplyPilot read and fill those frames when you open the extension; it still never reads pages on its own.

Discovered application questions

When the extension finds an unfamiliar application question, it stores the question locally here. Add an approved answer once, and it can be suggested the next time the same question appears.

Installer responsibility acknowledgment

This extension assists with data entry only. The installer is responsible for verifying all extracted details, answers, sensitive information, eligibility responses, and the final application before submission.

Advanced: import, export, or edit profile JSON

Safety defaults

  • Approved, non-high-risk fields can fill automatically; sensitive and unknown fields stay manual.
  • Submit buttons, CAPTCHA, and file uploads are never automated.
  • Unverified facts remain blank instead of being invented.
  • Do not store passwords, SSNs, passports, bank details, or authentication codes here.
