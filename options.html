Build profile from resume

Upload a resume to extract basic application facts. Extraction creates a proposal; it does not overwrite your approved profile automatically.

Discovered application questions

When the extension finds an unfamiliar application question, it stores the question locally here. Add an approved answer once, and it can be suggested the next time the same question appears.

Installer responsibility acknowledgment

This extension assists with data entry only. The installer is responsible for verifying all extracted details, answers, sensitive information, eligibility responses, and the final application before submission.

Safety defaults

  • Manual approval is required before fields are filled.
  • Submit buttons, CAPTCHA, and file uploads are never automated.
  • Unverified facts remain blank instead of being invented.
