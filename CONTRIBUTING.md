# Contributing

1. Keep all fixtures synthetic. Never add a real resume, phone number, email address, application answer, token, cookie, or employer data.
2. Keep external writes approval-gated. Do not add automatic application submission or CAPTCHA bypass.
3. Run `npm test` and `npm run public-scan` before opening a pull request.
4. Explain any new permission, host permission, storage field, or network request in the pull request description.
