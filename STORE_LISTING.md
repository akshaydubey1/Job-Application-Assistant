## Description

ApplyPilot helps you save time while completing job applications
without taking control away from you.

Import a resume, review the extracted profile proposal, and approve only the
details you want to use. When you scan a visible application page, the
extension maps common fields such as name, email, phone, location, education,
skills, LinkedIn, and GitHub. With automatic assistance enabled, approved
non-high-risk values can be filled immediately; sensitive and unfamiliar
questions remain manual. The extension does not submit the application.

When a site asks an unfamiliar question, the extension can save the question
locally in a reviewable question bank. Add an answer once, review it, and use it
as a suggestion the next time the question appears. Sensitive questions are
highlighted and are never answered by inference.

Privacy and control are built in:

• Profile, approved answers, and acknowledgment data stay in your browser's
  local extension storage.
• PDF/DOCX extraction is optional and can use a local parser running on your
  own computer.
• No resume or application data is sent to a developer-operated cloud service.
• Scanning requires an installer responsibility acknowledgment.
• Every proposed value is reviewable before it is used.
• The extension does not submit applications, bypass CAPTCHA, or automate file
  uploads.

This tool is an assistant for data entry, not an employment-eligibility or
application-decision service. You are responsible for verifying your resume,
answers, sensitive information, eligibility responses, and final application
before submission.
